== Lifecycle changes

* When a user's ID code (`EE...`) changes, the internal ID stays the same and still connects all the submissions the user has made. If the user has two eIDs, both are mapped to the same internal ID. The mapping in Identity & access is updated or extended, `USER-1234` does not change.
* When a case moves to another agency, the submission ID stays the same. The agency and the agency reference in the submission record are updated.
* When the notification provider is replaced, `SERVICE-Notification` stays the same and only the provider account ID (the external ID) changes.
